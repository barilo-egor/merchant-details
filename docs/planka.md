# Задачи в Planka

Общие правила для всех участников. Одинаковый файл лежит в rce, processing и merchant-details.

## Чья задача

- Задача относится к репозиторию, с которого началась работа. Если работа в одной репе потребовала правок в других, всё время и всё описание идут в задачу первой репы.
- Отдельная задача в другой репе — отдельная карточка.

## Где создавать задачи

Planka открывается в браузере: `https://task.rcetech.net`. Работать с ней только через веб: через интерфейс или API Planka в браузере под входом пользователя. В Planka пользователь входит сам: на поле пароля остановиться и попросить его войти.

«Создай карточку» или «создай задачу» значит: создать карточку в проекте «Разработка», на доске «Разработка», в колонке «К исполнению». Просьбы «перемести задачу», «закрой карточку» и подобные относятся к этой же доске.

Колонки доски «Разработка» по порядку: «К исполнению», «Нужен ответ», «В процессе», «Готовы», «В продакшене», «Архив». «Архив» — колонка типа `closed`: при переносе в неё Planka сама закрывает карточку. Задачу, которая уже выкачена, переносить в «В продакшене».

## Как писать карточки

- Описание короткое, простыми словами, без технических терминов: что изменилось для обменника и пользователей, а не какие классы поменялись.
- В описании таблицей указывать, на что сколько времени ушло: колонки «Что сделано» и «Время», последней строкой — «Итого».

## Оплата

У каждой карточки доски «Разработка» есть группа полей «Оплата». Каждое поле — сумма оплаты за задачу одному исполнителю, поля называются по никам исполнителей.

«Запиши оплату N» значит: вписать N в поле группы «Оплата» на карточке этой задачи. В какое поле писать, каждый раз уточнять у пользователя, самому не выбирать.

## Как менять

Через интерфейс Planka в браузере. Если действий много (например, массовый перенос), то через API Planka из того же браузера под входом пользователя, с токеном из cookie `accessToken`:
- создание: `POST /api/lists/<listId>/cards`;
- перенос и описание: `PATCH /api/cards/<id>` с `{listId, position}` и/или `{description}`;
- поле оплаты: `PATCH /api/cards/<cardId>/custom-field-values/customFieldGroupId:<groupId>:customFieldId:<fieldId>` с `{content: "N"}`. У каждой карточки своя группа «Оплата» со своими id полей: их берём из `GET /api/cards/<cardId>` (`included.customFieldGroups`, `included.customFields`).
